# Meu Caixa — sistema visual v4

## Direção

Editorial funcional: primeiro a legibilidade e a hierarquia do dinheiro; depois a estética. Sem neon, gradientes luminosos, padrões decorativos, dashboards de quatro cartões ou barras laterais duplicadas.

## Tipografia

- Títulos: Georgia com espaçamento editorial.
- Números monetários: Segoe UI / Arial com `font-stretch: normal`, `font-variant-numeric: tabular-nums` e espaçamento natural; nunca usar fonte display nos valores.
- Interface: Segoe UI / Inter / Arial; controles, tabelas e rótulos de fácil leitura.

## Navegação

- **Única navegação:** barra horizontal no topo.
- **Único controle de tema:** canto superior direito do cabeçalho.
- **Único seletor global de mês:** cabeçalho, nas telas que trabalham por mês.
- Ações financeiras nomeadas pelo que a pessoa fez, não por jargão contábil.

## Informação

- **Disponível na conta:** saldo inicial + recebimentos − gastos − dinheiro guardado + dinheiro retirado do investimento.
- **Gastos do mês:** somente despesas reais; não inclui transferência para CDB.
- **Guardado:** valor da aplicação cadastrada mais transferências e conferências de saldo.
- Verde, vermelho e azul sempre acompanhados de texto ou sinais; nunca cor isoladamente.
