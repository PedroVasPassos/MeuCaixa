MEU CAIXA — VERSÃO SIMPLIFICADA

1. Abra a pasta no VS Code ou Kiro.
2. No terminal: npm install
3. Depois: npm run dev
4. Abra o endereço mostrado pelo terminal.

O QUE MUDOU
- Menu em um lugar só (no topo)
- Tema em um botão só (no topo direito)
- Valores sem números esticados
- Layout mais limpo
- Botões simples para seu CDB

COMO COMEÇAR DE VERDADE
- Clique em "Começar com meus dados" para remover os valores fictícios.
- Vá em Ajustes e informe o dinheiro da conta sem o CDB.
- Vá em Dinheiro guardado e cadastre o saldo já investido.
- Use Anotar gasto/Recebi dinheiro para registrar o dia a dia.
- Use Guardei mais/Retirei dinheiro ao transferir valores entre conta e CDB.
- Use Conferir saldo para copiar o TOTAL mostrado no aplicativo do banco.

Atenção: nesta versão não há sincronização na nuvem; faça backup JSON em Ajustes.
